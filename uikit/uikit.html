Gruppa Info — UI Kit

Фундамент и библиотека компонентов для личного кабинета психологов и админ-панели. Система описывает, как выглядит и ведёт себя каждый интерфейсный элемент — без привязки к конкретным продуктовым экранам.

Accessibility

— Контраст текста соответствует WCAG AA (text-primary на background-page ≈ 10:1).
— Touch target минимум 44×44px для интерактивных элементов на мобильных.
— Статус всегда сопровождается текстом, не только цветом (см. Badge).
— Placeholder не заменяет Label — Label всегда присутствует отдельно.
— Focus-состояние одинаково для всех интерактивных компонентов (см. Focus System).
— Disabled-элементы визуально отличаются цветом текста и фона, не только opacity.
