# Статус проекта

Текущий реализованный этап: **Stage 1 — технический фундамент**.

## Работает сейчас

- стандартное Laravel 12 приложение на PHP 8.2.32;
- однокомандный запуск через Docker Compose;
- Nginx и MySQL 8.4.7 с healthchecks;
- отдельные MySQL-схемы для development и автоматических тестов;
- базовый Blade-layout и тестовая домашняя страница;
- локальный Bootstrap 5.3.8, `public/app.css` и `public/app.js` без build step;
- единое отображение UTC-дат в `Europe/Minsk`;
- единое форматирование целочисленных минорных денежных единиц с BYN по умолчанию;
- PHPUnit, Pint и Larastan/PHPStan уровня 5;
- Composer platform PHP 8.2.32 и явный список PHP-расширений.

## Намеренно не реализовано

Stage 2 и последующая продуктовая функциональность ещё не реализованы. В проекте пока нет `gp_*` моделей и таблиц, пользователей и ролей, аутентификации, административной панели, кабинета психолога, групп, заявок, платежей, workflow статусов, очередей продукта и внешних интеграций. Stage 3 дизайн-система также не реализована.

## Ограничения и открытые вопросы

- Production web server и production MySQL version ещё не выбраны; Docker-конфигурация предназначена только для разработки.
- Текущая страница является нейтральной технической проверкой, а не утверждённым продуктовым интерфейсом.
- Production deployment automation относится к последующим этапам.

Следующий запланированный этап по спецификации — Stage 2: схема данных и доменная модель. Он должен выполняться отдельной утверждённой задачей.
